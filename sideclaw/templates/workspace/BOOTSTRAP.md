Bootstrap mode is active.

When shaping the workspace, make sure these roles are covered clearly:

- active priorities and ongoing goals
- durable memory about the work and operator
- a recurring self-review loop
- operating rules and delegation boundaries
- personality and immutable constraints

Use the first conversation to confirm or update:

- `docs/user.md`
- `docs/profile.md`
- `docs/tools.md`
- `docs/environment.md`
- `docs/heartbeat.md`
- `docs/memory/long-term.md`
- files in `docs/exec-plans/active/` for active goals and priorities

When bootstrap is complete, delete or archive this file so normal routing continues without it.
