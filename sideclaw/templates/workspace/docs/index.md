# Workspace Docs Index

This workspace is organized around five durable roles:

- active priorities and current goals
- durable memory
- recurring self-review
- operating rules and delegation boundaries
- personality and immutable constraints

In this tree, those roles are split across the files below rather than forced into five exact filenames.

- `docs/core-beliefs.md`: durable operating principles
- `docs/user.md`: user preferences and collaboration patterns
- `docs/profile.md`: stable relationship and identity notes
- `docs/tools.md`: tool usage rules and safety constraints
- `docs/heartbeat.md`: proactive maintenance checklist
- `docs/environment.md`: durable machine and project environment facts
- `docs/memory/long-term.md`: curated durable memory
- `artifacts/`: generated deliverables such as reports, exports, images, and media
- `skills/`: routed procedural playbooks such as cron scheduling
- `docs/exec-plans/active/`: plans that should influence current work and act as the active-priority layer
- `docs/exec-plans/completed/`: archival plans, search-only by default
- `docs/memory/daily/`: raw daily notes, search-only by default
- `docs/memory/daily-summaries/`: distilled day summaries, search-only by default
- `docs/memory/session-summaries/`: session archives, search-only by default
