# Heartbeat

This file is the recurring self-review loop for the workspace. It should tell the agent what to re-check on its own: active goals, stale plans, missing memory updates, and anything else that should not depend on a fresh user request.

- Review active plans.
- Check whether durable docs need updates.
- Keep this file short so it can be loaded cheaply.
